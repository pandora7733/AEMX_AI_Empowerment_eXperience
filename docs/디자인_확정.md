# AEMX 앱 디자인 확정안

Penpot 파일 "새 파일 2"의 시안 8장으로 확정했습니다. 화면 이름은 시작, 마이크 1/6, 접근성 3/6, 연락처 5/6, 모델 준비 6/6, 홈 라이트, 홈 다크, 듣는 중 캡슐입니다. 화면 설명과 글자는 docs/디자인.md가 기준이고, 이 문서는 시안에서 뽑은 숫자입니다. 이름 "배재준"은 화면 글자에서 모두 "OOO"로 바꿨습니다.

## 기준

폰 화면 360 x 800, 좌우 여백 24, 글꼴 Noto Sans KR(없으면 시스템 한글 글꼴). 모서리는 알약 15, 카드 16, 예시 줄 14, 아이콘 칸 10. 그림자는 쓰지 않고 단색과 두 색 그라데이션만 씁니다.

## 색

라이트: 배경 #FFF8F2, 카드 #FFFFFF, 진한 글자 #2B1F2E, 보조 글자 #7C6B80, 안내 글자 #8A7A8E, 자주 #8A4A86, 분홍 #D9729B, 하늘색 #4BA3D3, 성공 초록 #34B27B, 초록 글자 #1F8A5B, 초록 알약 배경 #E6F6EE, 예시 아이콘 칸 #F7D6DC.
다크: 배경 #14131A, 카드 #1E1C27, 글자 #F4EEF6. 나머지 강조색은 같습니다.
캡슐: 배경 #12141C, 테두리는 하늘색에서 자주로 가는 그라데이션.
주요 버튼과 마이크 버튼: 자주 #8A4A86에서 분홍 #D9729B으로 가는 그라데이션.

## 홈 화면 위치와 크기

화면 맨 위 기준 y 값입니다. 아래 숫자는 x, y, 너비, 높이입니다.

앱 이름 AEMX는 74, 44, 20 굵기 800. 로고는 24, 36, 40 x 39. 설정 아이콘은 오른쪽 끝 312, 46, 22 x 22.
상태 알약은 24, 90, 172 x 30, 모서리 15, 배경 #E6F6EE. 안에 초록 점 8(왼쪽 37)과 글자 "호출을 기다리고 있어요" 13 굵기 700 #1F8A5B.
마이크 원 세 겹은 중심이 같습니다. 바깥 236, 중간 176, 버튼 116(122, 186). 바깥과 중간은 분홍 #D9729B을 아주 옅게(바깥 약 12%, 중간 약 22%) 깝니다. 버튼은 그라데이션이고 안의 마이크는 흰색(몸통 18 x 32 모서리 9, 받침 줄기 3 x 10, 받침 20 x 3).
"하이 에이맥스"라고 불러 보세요는 가운데 정렬 y 372, 19 굵기 800. 그 아래 y 402에 "화면이 꺼져 있어도 들을 수 있어요" 13.5 #8A7A8E.
상태 카드 셋은 y 432, 높이 58, 너비 99, 간격 8, x는 24, 131, 237, 배경 흰색, 모서리 16. 라벨 12 굵기 600 #7C6B80이 위(y 442), 점 7과 "준비됨" 13.5 굵기 800 #1F8A5B가 아래(y 462).
"이렇게 말해 보세요" 15 굵기 800은 y 506. 예시 줄 셋은 24, 534 / 584 / 634, 너비 312, 높이 44, 간격 6, 흰색 카드 모서리 14. 줄 안에 아이콘 칸 28 x 28(왼쪽 10, 모서리 10, #F7D6DC)과 글자 14.5 굵기 500(왼쪽 50). 아이콘은 자주 #8A4A86 단색: 재생 삼각형, 해, 말풍선.
"최근 실행" 15 굵기 800은 y 692. 줄은 y 718과 752 두 줄, 점 8과 명령 이름 14, 오른쪽 끝에 시간 12.5 #8A7A8E(2.3초, 2.0초).

## 다른 화면 공통

권한 단계 화면은 위에 로고와 AEMX, 오른쪽에 진행 점 6개와 숫자. 끝난 단계 점 초록, 지금 단계 길쭉한 자주, 남은 단계 연한 회색. 가운데 큰 아이콘 카드, 아래에 제목, 설명, 맨 아래 큰 버튼(높이 56, 모서리 28, 자주에서 분홍 그라데이션). 시안은 Penpot에서 보면서 간격을 맞춥니다.

## 모션

곡선은 cubic-bezier(0.2, 0, 0, 1)이고 시스템의 애니메이션 끄기를 따릅니다. 시작 로고 0.9배에서 1배 260ms. 단계 전환 180ms 페이드. 마이크 원 2.4초 주기로 1에서 1.06배(바깥 원은 위상을 늦게). 초록 알약은 같은 주기로 투명도 1에서 0.7. 예시 줄은 처음 열 때 50ms 간격으로 아래 8에서 올라오며 나타남. 캡슐 나타남 260ms(8 올라오며 0.96에서 1배), 사라짐 160ms. 중단을 누르면 파형과 깜빡임은 바로 멈춥니다.
