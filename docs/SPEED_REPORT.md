# 하이브리드 구조 속도 측정 (갤럭시 S25+, 2026-10-29 ~ 11-04)

형이 요구한 기준은 "모든 작업 5초, 길어도 8초"입니다. 아래 시간은 글 입력 기준으로 계획과 실행을 합친 값이고, 말 끝 판정 대기 시간은 따로 적었습니다.

## 이번에 확인한 속도의 구조

- 느린 곳은 LLM이 아니라 폰 화면 조작이었습니다. 클라우드 계획은 폰에서 0.4~0.7초, 간단한 명령의 기기 계획은 1.2~1.7초입니다.
- 유튜브는 YouTube Data API로 영상 id를 받아 바로 열어서 화면 조작을 거치지 않습니다(검색 약 0.8초).
- 교보문고와 카톡은 단계마다 기다리던 정착 대기를 줄여서 9.8초에서 6.0초, 8.1초에서 6.4초가 됐습니다.
- 쿠팡은 검색 제출을 키보드의 검색 동작으로 해야 해서 8.1초이고, 앱별로 성공한 방법을 기억해 두 번째부터 줄어듭니다.

## 클라우드 모델

- 첫 모델 qwen/qwen3.8-27b, 예비 openai/gpt-oss-120b (Groq 무료). 전체 5초, 첫 모델 3초 한도입니다.
- 같은 명령 20개 비교에서 qwen3.8-27b는 20/20 정답에 0.45초, gpt-oss-120b는 19/20에 0.77초, gpt-oss-20b는 18/20에 0.82초였습니다.
- 개인정보(카톡, 문자, 연락처, 전화)는 클라우드로 보내지 않고 폰 안 모델(Qwen3 1.7B, NPU)로만 처리합니다.

## 아직 남은 것

- 말 끝 판정(약 1.2초)이 더해지므로 실제 체감은 위 값에 1초 남짓을 더해서 봐야 합니다.
- 시끄러운 곳에서는 주변 소리를 말로 오인해 길게 듣는 구간이 보였고, 시연장 환경에서 확인이 필요합니다.
- 쿠팡 8.1초는 기준에 걸쳐 있습니다.
